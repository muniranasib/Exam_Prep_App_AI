Topic coverage

Source weighting

  • Primary — 2026 course and examination guide: official learning outcomes, 80-question format, scoring, required reading and exam skills.
  • Primary — 2026 labs and assignments: Python/Jupyter basics, Pandas, data cleaning, missing values, outliers, feature engineering, encoding, regression, classification and model evaluation.
  • Primary — required readings: selected Machine Learning Yearning chapters and Stanford AI Index Report 2026 sections listed in the exam guide.
  • Secondary inspiration — old mock exams (~15%): scenario-based multiple choice and foundational terms. The two uploaded PDFs appear to contain the same 39-question mock exam, so they are treated as one example, not two independent sources.

The app creates original questions. It does not reproduce the mock exam question-for-question. Additional questions have been added from the supplied lecture slides on AI foundations/history, Data for AI, supervised and unsupervised learning, regression, clustering, model evaluation, generative AI and prompt engineering. Each new lecture-derived explanation identifies its source lecture.

Important exam rules

  • Each practice quiz: Part A has 4 single-answer questions × 1 point.
  • Part B has 4 multiple-answer questions × 2 points. All correct options and no incorrect options are required for full credit.
  • Part C has 2 short written answers × 5 points, approximately 80–150 words each.
  • Maximum 22 points per practice quiz. For these short quizzes, grade labels are indicative percentages: A ≥ 90%, B ≥ 80%, C ≥ 60%, D ≥ 50%, E ≥ 40%, otherwise F. The official exam grading scale applies to the full 120-point exam, not directly to this 22-point practice quiz.
  • No code writing is required, but interpreting code fragments, model outputs, metrics and datasets may be tested.
