# DAVE3625 Exam Trainer — Short Quiz Edition

A mobile-friendly, local-first practice app for DAVE3625 Introduction to Artificial Intelligence.

## Quiz format
- Each quiz contains exactly 10 questions: 4 Part A (single answer), 4 Part B (select all that apply), and 2 Part C (short written answers).
- Maximum score: 22 points (4 + 8 + 10).
- Approximately 30-minute practice timer. The timer does not lock the quiz; answers remain editable and saved locally.
- Random question selection and shuffled answer options.
- Existing question bank retained and expanded: 139 Part A, 74 Part B and 23 Part C prompts.
- Part A/B are automatically marked. Part C includes model-answer guidance and self-assessment from 0–5 points.
- Answers, active attempt and history are saved in browser local storage.
- Light theme with mobile-friendly layout.

## Lecture material incorporated
New questions and written prompts have been added from the supplied lecture presentations, including:
- Basics and history of AI
- Data for AI
- Machine Learning I and II
- Machine Learning III: regression and clustering
- Model Evaluation
- Introduction to Generative AI and LLMs
- Prompt Engineering

Question explanations identify the relevant lecture source. Existing questions from the earlier bank are retained.

## Run locally
Open `index.html` in a modern browser.

## Publish/update on GitHub Pages
Upload the updated `index.html`, `README.md`, `icon-192.png` and `icon-512.png` to the root of the existing repository and commit the changes. GitHub Pages will publish the update automatically. If the browser continues showing the old version, refresh the page or clear the site's cached data.

## Privacy
Answers and history remain in the browser's local storage on the device. They are not sent to a server and do not sync between devices.
